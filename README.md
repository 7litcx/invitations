# 💜 منصة سول ميديا للدعوات الإلكترونية وتذاكر الدخول الذكية (Soul Media)

منصة إلكترونية ملكية فاخرة مصممة لإدارة وتصميم ومشاركة بطاقات الدعوة الذكية لمختلف المناسبات (حفلات الزفاف، حفلات التخرج، أعياد الميلاد، والاحتفالات الخاصة VIP)، مطابقة تماماً للهوية البصرية المعتمدة لـ **Soul Media** باللون اللافندر والبنفسجي الملكي الفاخر.

---

## 🌟 أبرز مميزات التصميم والواجهات الـ 12 المعتمدة

1. **صفحة تسجيل الدخول المنقسمة (Split Login)**:
   - لوحة فنية لافندرية مع بطاقة دعوة ثلاثية الأبعاد وعبارة *"كل مناسبة تستحق دعوة تليق بها ♥"*.
   - حقول الدخول، تذكرني، استرجاع كلمة المرور، وأزرار تجربة سريعة بنقرة واحدة.

2. **لوحة التحكم الرئيسية (Main Dashboard)**:
   - بنر ترحيبي فاخر بزخرفة زهرية: *"مرحباً بك مجدداً أحمد محمد علي"*.
   - 5 بطاقات إحصائيات متناسقة (إجمالي الدعوات 200، مقبولة 160، قيد الانتظار 20، معتذرة 80، متبقية 120).
   - رسم بياني دائري تفاعلي (Donut Chart 40%) بنسبة القبول والحضور.
   - قائمة "آخر الدعوات المرسلة" مع أشرطة تقدم ونسب تفاعلية.

3. **صفحة "دعواتي" (My Invitations)**:
   - شريط بحث وفلاتر متقدمة (المناسبات، الأنواع، الحالات).
   - **شبكة البطاقات الجرافيكية (Cards Grid)** مع مصغرات البطاقات وشارات الحالات وأزرار سريعة (عرض، تعديل، مشاركة، حذف).
   - زر التبديل الفوري بين شبكة الكروت وجدول التفاصيل.
   - حالة فارغة مع ظرف بريدي عائم وزر إنشاء الدعوة الأولى.

4. **إنشاء دعوة جديدة مع المعاينة الحية الفورية (Live Preview Wizard)**:
   - شريط خطوات (1. تفاصيل المناسبة -> 2. بيانات المدعو -> 3. معاينة البطاقة -> 4. تأكيد ونشر).
   - نموذج متكامل للمناسبة والمدعو.
   - **معاينة حية فورية**: تتغير نصوص البطاقة والباركود لحظياً أثناء كتابة المستخدم!

5. **تفاصيل الدعوة ومشاركتها (Invitation Details)**:
   - بطاقة دعوة فاخرة مع باركود QR عالي الدقة جاهز للتحميل.
   - مشاركة مباشرة بنقرة واحدة عبر **واتساب** أو منصة **X** أو **نسخ الرابط**.

6. **تحويل الدعوات وسجل العمليات (Transfer & Logs)**:
   - تحويل كوتا أو دعوات لمستخدمين آخرين مع عداد (+ و -) وسجل بالعمليات المنفذة.

7. **إدارة الفعاليات والمستخدمين (Events & Users)**:
   - جداول متطورة لمتابعة نسب حضور الفعاليات وصلاحيات الأعضاء والتحكم بالكوتا.

8. **التجاوب الكامل ونسخة الجوال (Mobile Experience)**:
   - شريط تنقل سفلي للهواتف الذكية (الرئيسية، دعواتي، إنشاء، تحويل).
